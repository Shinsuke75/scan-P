# scan-P

ブラウザだけで完結する**書類の台形補正（ドキュメントスキャナ）**Webアプリです。
画像をアップロードし、4点（書類の角）を合わせて射影変換（台形補正）し、
カラー / グレー / 白黒（適応的2値化）で仕上げて保存できます。バックエンド不要・フロントエンドのみ。

公開：https://shinsuke75.github.io/scan-P/

## 特長
- **元解像度のまま補正**（表示は縮小ビュー、変換は元画像座標）。ボケない。
- **射影変換は WebGL**（OpenCV 非依存・追加DLゼロ・GPUで高速）。WebGL不可時は純JSフォールバック。
- **自動枠検出は純JS**（大津の二値化＋最大明領域の四隅）。任意ボタンで実行、重い依存なし。
- **指で快適に操作**：Pointer Events 統一、ハンドルをつかんだ時だけスクロール抑止（それ以外はページスクロール可）、ルーペ（拡大鏡）付き。
- 頂点は画像の外（余白）にも置け、辺は隣接2辺の向きを保ったまま平行移動できる。
- スキャン風フィルタ（白黒は濃さ調整可）、90°回転、PNG/JPEG保存、スマホは写真アルバムへ保存（Web Share）。
- iOS Safari 対策（テクスチャ/ルーペ描画/Canvas上限）を実装。
